# Setup guides

Backlane is a remote MCP server. Every client needs the same URL:

```
https://app.getbacklane.com/mcp
```

You sign in with your Backlane account in the browser. Your assistant then
sees the marketplace connections of your organization.

- [Claude Code](claude-code.md)
- [Claude (web & desktop)](claude.md)
- [ChatGPT](chatgpt.md)
- [Cursor](cursor.md)
- [VS Code (GitHub Copilot)](vscode.md)

Connect your marketplace accounts (OTTO Market, Kaufland, Mirakl) in the
[Backlane app](https://app.getbacklane.com/app), not in the chat.
