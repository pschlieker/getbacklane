# ChatGPT

1. Settings → Plugins → Browse directory → **Add** → **Add custom MCP server**.
2. Fill in:
   - Name: `Backlane`
   - Description: `Marketplace APIs (orders, offers, inventory)`
   - Connection (Server URL): `https://app.getbacklane.com/mcp`
   - Authentication: OAuth (leave the advanced OAuth settings untouched)
3. Tick "I understand and want to continue" → **Create as a plugin** → sign in.

Ask: *"Is Backlane working? Which marketplaces are connected?"*
